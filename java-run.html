Java を書いて動かす練習

コードを書いて「実行」を押すと、ブラウザの中で本当に Java が動きます。表示された結果が問題どおりなら正解です。

Java を準備しています…（はじめて開いたときは、1分くらいかかることがあります）

※ Java 8 の書き方で動きます（List.of や var など、Java 9 以降の書き方は使えません）。キーボードからの入力（Scanner）も使えません。
※ 無限ループになると止められないので、そのときはページを再読み込みしてください。

正解した問題と書きかけのコードは、このブラウザに記録されます。
