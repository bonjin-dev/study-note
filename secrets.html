adjust 一、なぜ非同期で詰まるのか

JavaScriptは単一の糸（スレッド）で動く。重い処理で画面を止めぬため、約束（Promise）を交わして後から結果を受け取るのが理である。

code 二、定石の型（堅牢なる例外捕捉）

DojoAsync.js ES2022 
// 非同期奥義：堅牢なる例外捕捉
async function fetchDojoData(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) {
      throw new Error(`通信不首尾: ${res.status}`);
    }
    return await res.json();
  } catch (err) {
    console.error("修行の失敗を検知:", err.message);
    return null;
  }
}

lightbulb 三、凡人の勘所

await は async の結界の中でのみ使える。Promise.all で並列に走らせる技法も忘るべからず。直列に待ちすぎると道場の門が詰まる。
